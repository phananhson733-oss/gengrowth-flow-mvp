- 修复建议：明确"无 Reddit 时不发精修线 T1"或接 Quora/Twitter 兜底 (P2 决策)

### R3 — `cost-tracking` tab 无回填

- 修复：把 LLM orchestrator + DataForSEO mine + RAG 调用写一行 (本次 P0)
